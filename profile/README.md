# ngx-zen

`ngx-zen` is a collection of Angular packages for adding common UI and utility features to Angular apps.

## Featured project

### [`@ngx-zen/mat-password-meter`](https://github.com/ngx-zen/mat-password-meter)

Angular Material password strength components with a signals-based API.

- `PasswordStrengthComponent` combines password policy checks with zxcvbn entropy analysis.
- `PasswordRulesComponent` handles rule-based validation without loading zxcvbn.
- `PasswordAnalysisComponent` provides entropy feedback without policy enforcement.

Try the demo: <https://ngx-zen.github.io/mat-password-meter/>

Install:

```bash
npm install @ngx-zen/mat-password-meter zxcvbn
```
